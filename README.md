# Data-Validation-Java Student Application

📌 About the Project

This project is a simple Java application developed as part of my NQF Level 5 System Development studies.

The application was created using Java and Apache NetBeans and demonstrates basic programming concepts such as user input, validation checks, conditional statements, and displaying information to the user.

🎯 Purpose of the Application

The purpose of this application is to demonstrate how a basic Java application can:

* Accept information from the user
* Validate user input
* Check login details
* Display appropriate messages
* Use if, else if, and else statements
* Provide a simple and user-friendly interface

🛠️ Technologies Used

* Java
* Apache NetBeans
* Java Swing
* GitHub

🎨 Application Design

The application uses a simple and clean design.

* Background: Light grey
* Font: Black
* Headings: Black
* Layout: Simple and easy to understand

✅ Validation Checks

The application includes validation checks to make sure that the information entered by the user is correct.

Examples include:

* Checking that the username is correct
* Checking that the password is correct
* Displaying an unsuccessful message when incorrect login details are entered
* Preventing incorrect information from being accepted

🧪 Testing

The application was tested using different inputs to make sure that the validation checks work correctly.

Test Examples

Test	Input	Expected Result
Correct username and password	Correct details	Login successful
Incorrect username	Wrong username	Login unsuccessful
Incorrect password	Wrong password	Login unsuccessful
Incorrect username and password	Wrong details	Login unsuccessful
